# ADR-009: Консервативная стратегия географического покрытия

- Статус: принято
- Дата: 2026-08-05

## Контекст

Публичная страница Route Details API явно заявляет построение маршрутов в России,
Абхазии, Турции, Азербайджане, Армении, Казахстане, Кыргызстане, Таджикистане,
Беларуси, Грузии, Узбекистане и Молдове
([официальная страница продукта](https://yandex.ru/maps-api/products/router-api)).
Лицензионные определения перечисляют более широкий набор картографических баз,
но это не равнозначно гарантии автомобильного routing для каждой точки.

## Решение

- Публиковать в capability endpoint только 12 стран из явного product claim.
- Не реализовывать самодельные bounding boxes стран: координата у границы,
  анклавы и route через несколько стран делают такую проверку ненадёжной.
- Валидировать только WGS84 диапазоны, затем доверять результату официального
  Router API. `no route` не превращать в утверждение, что страна не покрыта.
- Вне консервативного списка показывать доступность как `UNKNOWN`, а не
  `UNSUPPORTED`, пока договор/официальная документация не подтверждают обратное.
- Не отправлять координаты в metric labels или операционные логи. Наблюдаемость
  покрытия строится на грубых, privacy-reviewed агрегатах выше provider boundary.
- При provider error/out-of-coverage orchestrator возвращает degraded/no-route и
  не обещает «свободную» дорогу.

## Последствия

Некоторые фактически строящиеся маршруты вне списка могут быть скрыты продуктовой
политикой до проверки договора. Это предпочтительнее ложного обещания покрытия.
Изменение списка требует повторного official capability spike и обновления этого
ADR; маркетинговый текст без технической/договорной опоры недостаточен.
