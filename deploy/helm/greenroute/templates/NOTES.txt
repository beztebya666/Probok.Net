Set config.trustedProxyCIDRs to the exact ingress-controller source CIDRs before exposing the service through a reverse proxy.
YANDEX_GEOCODER_API_KEY is optional only when address suggestion/resolution is not offered; do not assume the Router key grants Geocoder entitlement.

The chart never creates secret values. Provision the secret with External Secrets, Sealed Secrets, SOPS or the platform secret manager before installation.

Reference values use explicit non-latest version tags, but tags are not treated as immutable. A release pipeline must set each images.*.digest to the signed sha256 manifest digest; when supplied, the digest takes precedence over the tag. Multi-architecture manifest digests differ from per-platform image digests, so admission policy and signing must use the same digest form as the deployed image reference.
